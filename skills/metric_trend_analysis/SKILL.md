# 指标趋势分析

适用场景：
用户询问设备某个监控指标在一段时间内的变化趋势、峰值、异常波动或是否持续升高/降低。

执行流程：
1. 确认用户提供了设备 IP；缺少 IP 时先向用户询问，不调用工具猜测设备。
2. 如果用户没有提供明确的指标名称，调用 `list_metric_names` 获取该设备可用指标；如果指标名称明确，直接使用用户提供的名称。
3. 如果待查询指标不超过 5 个，对每个指标分别调用 `get_metric_range` 获取时间序列。用户没有指定时间范围时使用默认最近 1 小时；用户指定了范围时按用户范围传入。
4. 如果待查询指标超过 5 个，不逐个调用 `get_metric_range`；改为调用 `query_device_by_ip` 获取设备综合状态，并明确说明这不是全部指标的历史趋势。
5. 只有在历史数据不足以回答“当前值”时，才补充调用 `get_realtime_metric`。
6. 依据工具返回的数据说明趋势、峰值、低谷和明显异常；没有数据或数据不足时明确说明，不能自行推断。

约束：
- 只能调用当前 Agent 已授权的 MCP 工具。
- 工具调用可以分多轮进行，但每一步必须依据前一步工具结果。
- 不要把指标名称列表本身当作趋势结论。
- 单轮最多调用 5 次 `get_metric_range`。
- `query_device_by_ip` 返回的是设备当前综合状态，不能描述为过去一段时间的指标趋势。
- 超过 5 个指标时，应告知用户本次仅提供综合状态概览，并建议用户指定不超过 5 个指标后分批查询。
